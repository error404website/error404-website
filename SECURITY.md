# Security policy

This repository is the source of the ERROR_404 / ARCHIVE_404 website: a static site built with Vite and hosted on Netlify. It has no server code, accounts or database. The only data it collects is the booking form, handled by Netlify Forms.

## Reporting a problem

If you find a security issue (for example a way to inject content into the site, abuse the contact form, or a vulnerable dependency), **please don't open a public issue.** Report it privately instead:

- Use GitHub's **[Report a vulnerability](https://github.com/error404website/error404-website/security/advisories/new)** form, or
- Send a message through the SIGNAL contact form on the website, marked _security_.

Please include what you found, how to reproduce it, and which page or file it affects. We'll acknowledge reports within a few days and credit you if you'd like once it's fixed.

Dependencies are kept up to date automatically by Dependabot.
